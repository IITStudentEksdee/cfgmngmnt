# depgrapher — визуализация графа зависимостей пакета (apt)

CLI-инструмент для построения и визуализации графа зависимостей пакета
Debian/Ubuntu (apt) **без использования менеджеров пакетов и сторонних
библиотек**: только стандартная библиотека Python ≥ 3.10 (проверено на 3.14).

## Возможности

- транзитивный граф зависимостей: рекурсивный BFS по пакетам репозитория;
- циклические зависимости обнаруживаются и перечисляются (включая
  самозависимость, цикл длины 1); «алмазы» (общие зависимости) циклами
  не считаются;
- сравнение версий Debian согласно Debian Policy §5.6.12 (эпоха, upstream,
  ревизия, символ `~`), проверено на тестовых векторах dpkg;
- разбор `Depends` с альтернативами (`|`) и операторами версий (`<<`, `<=`, `=`, `>=`, `>>`, `<`, `>`, `!=`);
- визуализация: **PNG** (собственный растреризатор на `struct` + `zlib`), **SVG** и **ASCII-дерево** (`-a tree`) — без
  Cairo, PIL и прочих зависимостей;
- режим `--mode file` — офлайн-проверка на тестовых репозиториях в
  простом текстовом формате.

## Требования

- Python ≥ 3.10, стандартная библиотека;
- опционально: доступ в сеть (режим `url`).

## Использование

```
python -m depgrapher --help
```

### Примеры

**Реальный apt-репозиторий** (Ubuntu 24.04 «noble», пакет `curl`):

```
python -m depgrapher -p curl \
    -s http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages \
    -v 8.5.0-2ubuntu10 -o out/curl.png -a tree
```

**Тестовый репозиторий** (сценарии: цепочка, алмаз, цикл, глубина,
неразрешимая зависимость — см. `testrepos`):

```
python -m depgrapher -p A -s testrepos/chain.txt -m file -o out/chain.png
python -m depgrapher -p A -s testrepos/cycle.txt -m file -o out/cycle.png
```

### Параметры

| Параметр        | Описание                                                                        |
|-----------------|---------------------------------------------------------------------------------|
| `-p, --package` | имя анализируемого пакета (обязательно)                                         |
| `-s, --source`  | URL-адрес Packages-индекса или путь к файлу тестового репозитория (обязательно) |
| `-m, --mode`    | режим репозитория: `url` (реальный apt) / `file` (тестовый; по умолчанию `url`) |
| `-v, --version` | версия пакета (формат Debian); по умолчанию — самая высокая в репозитории       |
| `-o, --output`  | имя выходного PNG-файла (по умолчанию `dependency-graph.png`)                   |
| `-a, --ascii`   | ASCII-дерево зависимостей: `off` / `tree` (по умолчанию `off`)                  |

### Коды выхода

| Код | Значение                                                         |
|-----|------------------------------------------------------------------|
| 0   | успех                                                            |
| 2   | неверные аргументы командной строки                              |
| 3   | несогласованные параметры (например, `--mode file` с URL)        |
| 4   | ошибка репозитория (скачивание, разбор, пакет/версия не найдены) |
| 5   | ошибка отрисовки или записи файлов                               |

## Как строится граф

БFS с рекурсией: функция `_bfs_layer` обрабатывает текущий слой (фронт)
и вызывает саму себя для следующего. Зависимость разрешается к **самой высокой** версии, удовлетворяющей ограничению;
при альтернативах
выбирается первая удовлетворяемая. Ребро к уже посещённому узлу — **обратное**: если этот узел является предком в
BFS-дереве, формируется
цикл (`describe_cycles` восстанавливает его); иначе это «алмаз» (конфлюэнция). Неразрешённые зависимости выносятся в
список и
отображаются красным на картинке.

## Формат тестового репозитория

```
# ИМЯ ВЕРСИЯ: ЗАВИСИМОСТЬ1, ЗАВИСИМОСТЬ2, ...
A 1.0: B, C(>=2.0)
B 1.0: D|E        <- альтернативы
C 2.0:
D 1.0             <- двоеточие можно опустить, если зависимостей нет
```

Пакеты называются большими латинскими буквами (допускаются цифры).
Зависимости разделяются запятыми, альтернативы — символом `|`,
ограничение версии — в скобках (`B(>=2.0)`). Строки, начинающиеся с
`#`, и пустые строки игнорируются.

## Тесты

```
python -m unittest discover -s tests
```

Покрывают: версии Debian (векторы dpkg), парсер `Depends`,
Packages-индекс, тестовые репозитории, граф (циклы, алмазы,
самозависимость), рендер (PNG-байты, пиксели, XML), CLI (параметры, валидация, коды выхода). Итог: **58 тестов, все
проходят**.
